# 极简新标签页（blank-newtab）

一个 Chrome / Chromium 内核浏览器的**新标签页扩展**（MV3），替换浏览器默认新标签页。

## 为什么有这个仓库

Helium 浏览器默认空白页有三个限制：快捷方式只能一行、图标不能自定义、图标下标题显示字数太少。这个扩展保留空白页的干净，只把这三条限制拆掉。

## 功能

- **多行快捷方式网格**：图标自动排满换行，行数不限；窗口足够宽时每行最多 9 个，窗口变窄自动减列换行
- **自定义图标**：编辑时可上传本地图片；不上传则自动抓网站 favicon；再不行显示首字母色块
- **两行标题**：图标下方名称最多显示两行（约 10 个汉字）
- **编辑模式**：右下角铅笔按钮进入，页面平时完全纯净
- **深浅色跟随系统**，纯 CSS 实现
- **零权限、零网络依赖**：扩展详情页权限列表为空；所有数据只存本机浏览器

## 安装

**方式一：网页下载（推荐，无需命令行）**

1. 点本仓库绿色 `< > Code` 按钮 → `Download ZIP`
2. 解压到一个**长期不动的位置**（如 `D:\extensions\`）。
   注意：浏览器直接引用文件夹本身，之后挪动或删除该文件夹，插件就会失效。不要解压在"下载"文件夹里用。
3. 浏览器地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`，Helium 相同）
4. 打开右上角"开发者模式"
5. 点"加载已解压的扩展程序"，选中解压出的文件夹（名称形如 `blank-newtab-main`，是 GitHub 自动加的分支后缀，正常）

**方式二：git**

```bash
git clone https://github.com/xiaonaimao/blank-newtab.git
```

然后同上，扩展页加载 clone 出的文件夹。

## 使用

- **点图标**：跳转对应网站
- **点末尾"+"**：添加快捷方式（名称、网址必填，图标可选）
- **右下角铅笔**：进入编辑模式（图标右上角浮出红色 ×、底部出现"编辑中"提示条、铅笔变蓝色对钩）
  - 编辑模式中：**点图标本体** = 修改（改名 / 改网址 / 换图标）；**×** = 删除；**蓝色对钩**或 `Esc` = 退出编辑
- 数据（快捷方式列表、上传的图标）保存在浏览器本机 localStorage，重启浏览器不丢

## 更新版本

1. 用新的三个文件（manifest.json、nav.html、nav.js）覆盖原文件夹内容
2. 扩展管理页点该插件卡片上的刷新按钮
3. 卡片上版本号变化即生效（当前 2.2.1，见 manifest.json）

已安装状态下覆盖文件不会丢失数据；**移除扩展再重装会清空全部数据**，能不重装就不重装。

## 注意

- 每行 9 个图标需要窗口宽度 ≥ 960px，窗口更窄时自动降为 8/7/6... 列，属正常响应式行为
- 上传的图标会被压缩为 128×128 后存储，防止撑爆浏览器存储配额
- 新标签页打开后键盘焦点仍在地址栏，直接打字即可搜索 / 输网址
